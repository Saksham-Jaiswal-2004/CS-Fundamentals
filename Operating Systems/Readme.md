Operating Systems

Overview

Operating systems manage hardware resources and provide essential services for programs. This section explains how processes run, how memory is managed, how the CPU is scheduled, and how files and I/O are handled.

Topics Covered

- OS fundamentals and responsibilities
- Process and thread management
- CPU scheduling algorithms and policies
- Synchronization (mutexes, semaphores, monitors) and concurrency
- Deadlocks (conditions, detection, prevention, avoidance)
- Memory management (paging, segmentation)
- Virtual memory and demand paging
- File systems (inodes, allocation, journaling)
- I/O systems and device management

Learning Outcomes

- Understand how programs execute and share resources
- Analyze and compare scheduling and synchronization strategies
- Reason about memory, storage, and I/O behavior

How to Use

- Start with process/thread basics, then scheduling and synchronization
- Reinforce memory concepts with paging/VM examples and diagrams
- Compare file systems and experiment with OS tools to observe behavior
