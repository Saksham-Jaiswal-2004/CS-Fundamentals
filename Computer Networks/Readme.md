Computer Networks

Overview

This section explains how devices communicate and how data flows across networks and the internet. It connects core protocols and models with practical behavior seen in modern applications and services.

Topics Covered

- Networking basics and terminology
- OSI and TCP/IP models (layered responsibilities)
- Physical and Data Link layers (framing, MAC, switching)
- Network layer (IP addressing, routing, CIDR, NAT)
- Transport layer (TCP vs UDP, congestion control, reliability)
- Application layer (HTTP/HTTPS, DNS, SMTP, FTP)
- Error detection, flow control, and reliability mechanisms
- Network security fundamentals (TLS, certificates, basic threats)

Learning Outcomes

- Understand core protocols and how they interact across layers
- Diagnose common network issues using mental models and tooling
- Build and debug networked applications with confidence

How to Use

- Map application behaviors to the corresponding stack layers
- Use tools like ping, traceroute, curl, and browser devtools to observe protocols
- Compare protocol choices (e.g., HTTP/2 vs HTTP/3, TCP vs UDP) for requirements
